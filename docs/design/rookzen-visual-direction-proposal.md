# Rookzen visual direction proposal

## Current status

The audit and direction phase is complete. General Rookzen production implementation has begun with foundational branding, design tokens, and the play-first web shell. The specific hybrid proposed here has neither been approved as the permanent visual direction nor started as a dedicated implementation.

## Explored directions

- **A — The Quiet Match Room**
- **B — The Competitive Table**
- **C — The Annotated Game**

These directions are proposals for evaluation, not approved production systems.

## Recommended hybrid

The current recommendation is to use Direction A as the overall product foundation, Direction B for the live competitive play workspace, and Direction C for review and learning surfaces. This recommendation remains subject to owner approval.

## Non-negotiable product constraints

- Keep the experience chess-first and the board central.
- Use a dark-first visual foundation.
- Maintain a calm, clear, and modern product character.
- Treat accessibility as a baseline requirement.
- Support Arabic and RTL composition as first-class concerns.
- Preserve complete keyboard support and visible focus.
- Respect reduced-motion preferences.
- Design mobile as a deliberate composition, not a compressed desktop layout.
- Avoid generic SaaS card-wall styling.
- Avoid teal-, green-, or purple-led branding.

## Explicitly unresolved decisions

- Final fonts
- Final logo and rook mark
- Final board colors
- Final semantic status palette
- Final review verdict system
- Final navigation grouping
- Final Arabic typography

## Next-step gate

No production implementation should begin from this document alone.
Owner approval of the visual direction or hybrid is still required.

# Rookzen audit sources

- [FABLE_ASTRA_FULL_AUDIT.md](FABLE_ASTRA_FULL_AUDIT.md) is the authoritative original historical Fable + Astra audit and launch-readiness baseline.
- [ROOKZEN_VISUAL_HANDOFF.md](ROOKZEN_VISUAL_HANDOFF.md) is the authoritative historical visual and design handoff. It includes recommendations and unresolved owner decisions; it is not blanket approval to implement a permanent visual direction.
- [RECOVERY_INDEX.md](RECOVERY_INDEX.md) is the artifact-recovery inventory supporting the visual audit. It is not a substitute for the Fable + Astra audit.

Historical findings must be re-verified against current `main`. A finding in an old audit does not mean it remains open. Future remediation should distinguish the original historical finding, the currently verified open issue, an already-fixed or merged issue, and an optional or deferred item.

Future agents should prefer a current remediation ledger when one exists, and consult the original audit for source and acceptance context. This index does not create a remediation ledger.
